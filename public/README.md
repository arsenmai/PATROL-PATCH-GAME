# Optional generated assets

Both files were generated with Higgsfield: the key art with GPT Image, the robot with Tripo text-to-3D.

The game is fully playable without anything in this folder: every model and surface is procedural.
If these files are present they are picked up automatically at start-up.

| File | Used for |
| --- | --- |
| `title.jpg` (or `title.png`) | Background of the main menu |
| `models/guard.glb` | Body of the security robots (replaces the primitive robot) |
